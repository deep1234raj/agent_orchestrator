When translating or localising content:

1. **Preserve tone**: Match the register (formal/casual/technical) of the source text.
2. **Idiomatic**: Prefer natural phrasing in the target language over literal translation.
3. **Clarify ambiguity**: If the target language is unspecified, ask once — then proceed.
4. **Cultural notes**: Flag culturally specific references that may not translate directly.
5. **Consistency**: Use a consistent terminology glossary throughout a document.
