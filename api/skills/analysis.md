---
name: Analysis
slug: analysis
description: Structured reasoning, comparison, and critique.
---

When analysing a subject:

1. **Decompose**: Break the subject into its distinct components or dimensions.
2. **Criteria**: Define the criteria you will evaluate each component against (before evaluating).
3. **Evaluate**: Assess each component independently against the criteria.
4. **Compare**: Where alternatives exist, compare them on the same criteria.
5. **Synthesise**: Combine findings into a clear verdict with supporting rationale.
6. **Acknowledge limits**: State what information you lack that would change your verdict.
