When producing written content:

1. **Structure**: Open with a one-sentence summary. Use clear headings (##) for sections.
2. **Paragraphs**: Keep each paragraph to 3–5 sentences. One idea per paragraph.
3. **Voice**: Active voice throughout. Avoid passive constructions.
4. **Brevity**: If a word can be cut without losing meaning, cut it.
5. **Close**: End with a one-sentence takeaway that crystallises the key message.
