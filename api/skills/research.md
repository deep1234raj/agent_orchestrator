When researching a topic, follow this procedure:

1. **Gather sources**: Use `web_search` to find at least 3 credible sources on the topic.
2. **Cross-verify**: For any factual claim, confirm it appears in multiple sources.
3. **Cite**: Include source URLs next to each fact or data point you reference.
4. **Distinguish**: Flag whether each source is primary (original study/data) or secondary (commentary).
5. **Flag contradictions**: If sources disagree, call it out explicitly rather than picking one silently.
