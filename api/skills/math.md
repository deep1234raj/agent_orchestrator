When solving numerical problems:

1. **Plan**: State the formula or approach before computing.
2. **Use the tool**: Call the `calculator` tool for all arithmetic — do not compute mentally.
3. **Show steps**: Display each intermediate result, not just the final answer.
4. **Verify**: After obtaining a result, perform a sanity check (e.g. order-of-magnitude estimate).
5. **Units**: Always include units in intermediate and final results.
